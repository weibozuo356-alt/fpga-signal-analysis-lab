## 材料说明

仓库中的结论区分为四类：

1. **理论计算**：由时钟频率和代码参数推导；
2. **仿真结果**：由Vivado行为仿真波形验证；
3. **上板实测**：由开发板照片或仪器记录支撑；
4. **待补材料**：工程已经完成，但相关照片或测量数据尚未归档。

任务一至任务三已经形成代码、原理、仿真、实测和报告闭环；后续继续整理任务四和任务五。任务三仍可补存1 kHz数码管照片及同条件示波器参考读数，以加强独立精度证据。

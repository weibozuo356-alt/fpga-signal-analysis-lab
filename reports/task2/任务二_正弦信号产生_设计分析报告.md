## 1. 设计任务与系统位置

任务二要求设置不同频率控制字产生正弦信号，并将产生结果与示波器测量值对应。本设计使用三个拨码开关选择1 kHz、10 kHz、50 kHz、1 MHz、1.5 MHz和2 MHz六个频点，由DDS Compiler产生数字正弦样本，再通过外接AD/DA板的14位DAC输出模拟信号。

## 3. 核心原理与参数设计

### 3.1 时钟设计

最终Clock Wizard输入100 MHz，输出10 MHz与50 MHz，并启用 `locked`。任务二使用10 MHz作为DDS和DAC的采样时钟；50 MHz在最终集成工程中供后续ADC、测频和FFT使用。

$$
T_s=\frac{1}{10\ \text{MHz}}=100\ \text{ns}
$$

![Clock Wizard配置](../../assets/task2/task2_clock_wizard_configuration.png)

### 3.2 DDS相位累加原理

32位相位累加器在每个采样时钟沿增加一次频率控制字 $K$：

$$
P[n+1]=(P[n]+K)\bmod2^{32}
$$

相位绕一圈所需的采样次数决定输出周期，因此：

$$
f_{out}=\frac{Kf_s}{2^{32}}
$$

目标频率对应的控制字为：

$$
K=\mathrm{round}\left(\frac{f_{out}2^{32}}{f_s}\right)
$$

当 $f_s=10\ \text{MHz}$、相位宽度为32位时，控制字最小变化1，对应理论频率分辨率：

$$
\Delta f=\frac{10\,000\,000}{2^{32}}
=0.0023283064365\ \text{Hz}
$$

本次任务在老师评分表中可填写：

```text
已配置并实测的频率变化范围：1 kHz～2 MHz
DDS理论频率分辨率：约0.002328306 Hz
```

频率范围是本实验实际配置并验证的六个频点范围；分辨率是32位DDS控制字的理论步进，两者不能混为同一指标。

### 3.2.1 `freq_sel=111`显示理论频率分辨率

为了能直接在开发板上查看任务二的理论频率分辨率，最终代码把`freq_sel=111`设置为分辨率显示选择码。八位数码管不能完整显示无限小数，因此保留七位小数：

$$
0.0023283064365\ \text{Hz}\approx0.0023283\ \text{Hz}
$$

代码先把该数值放大$10^7$并四舍五入为整数23283，复用原有Double Dabble电路得到BCD `00023283`，再在最左侧数字0之后点亮小数点，最终显示：

```text
0.0023283
```

操作条件为SW4=1、SW3=0、`{SW2,SW1,SW0}=111`。该功能只覆盖频率页面的数码管数据源；SW4=0仍显示学号，SW3=1仍显示THD。`111`没有新增DDS输出频点，DDS仍保持原来的默认1 kHz输出，因此任务一、任务二六档输出、任务三测频以及任务四、任务五THD链路均不改变。

### 3.3 六个频率控制字

| 选择码 | 目标频率 | 控制字K | K对应理论频率 | 每周期采样点数 |
|---|---:|---:|---:|---:|
| `000` | 1 kHz | 429497 | 1000.000630 Hz | 10000 |
| `001` | 10 kHz | 4294967 | 9999.999311 Hz | 1000 |
| `010` | 50 kHz | 21474836 | 49999.998882 Hz | 200 |
| `011` | 1 MHz | 429496730 | 1000000.000931 Hz | 10 |
| `100` | 1.5 MHz | 644245094 | 1499999.999069 Hz | 约6.67 |
| `101` | 2 MHz | 858993459 | 1999999.999534 Hz | 5 |

`110`保留给任务五外接信号模式；`111`的DDS控制字仍回到1 kHz，仅在频率显示页面显示0.0023283 Hz理论分辨率。

### 3.4 DDS IP配置

最终工程中的 `dds_sine`采用：

- 10 MHz系统时钟，单通道；
- Phase Generator and SIN/COS LUT；
- Standard模式，Noise Shaping为None；
- 32位相位累加器；
- 16位相位角；
- 可编程Phase Increment，通过 `S_AXIS_CONFIG`更新；
- Sine输出，16位二进制补码；
- 自动流水线延迟7周期。

![DDS主要配置](../../assets/task2/task2_dds_configuration.png)

32位相位表示“当前走到圆周的哪个位置”，16位输出表示“该相位对应的正弦幅度”。两者是不同物理量。低位相位仍保存在累加器中并继续累积，因此相位角和幅度输出较窄不会把频率分辨率降成16位。

## 4. 带注释的关键Verilog实现

最终集成源文件已归档为：[id_display.v](../../code/final/id_display.v)。本节只列出任务二相关功能块。

### 4.1 频率控制字与选择函数

```verilog
// K = round(f_out * 2^32 / 10 MHz)
localparam [31:0] K_1KHZ   = 32'd429497;
localparam [31:0] K_10KHZ  = 32'd4294967;
localparam [31:0] K_50KHZ  = 32'd21474836;
localparam [31:0] K_1MHZ   = 32'd429496730;
localparam [31:0] K_1P5MHZ = 32'd644245094;
localparam [31:0] K_2MHZ   = 32'd858993459;

function [31:0] select_frequency_word;
    input [2:0] select;
    begin
        case (select)
            3'b000: select_frequency_word = K_1KHZ;
            3'b001: select_frequency_word = K_10KHZ;
            3'b010: select_frequency_word = K_50KHZ;
            3'b011: select_frequency_word = K_1MHZ;
            3'b100: select_frequency_word = K_1P5MHZ;
            3'b101: select_frequency_word = K_2MHZ;
            default: select_frequency_word = K_1KHZ;
        endcase
    end
endfunction
```

`110`和`111`未分配给任务二的有效频点，默认输出1 kHz，避免产生未定义控制字。

### 4.2 开关同步与单周期配置脉冲

```verilog
always @(posedge clk_10m) begin
    // 两级同步异步拨码开关
    freq_sel_meta <= freq_sel;
    freq_sel_sync <= freq_sel_meta;

    // 默认拉低，只有需要更新时才在本周期置高
    dds_config_valid <= 1'b0;

    if (!clk_10m_locked) begin
        dds_config_sent <= 1'b0;
    end else if (!dds_config_sent ||
                 (freq_sel_sync != freq_sel_last)) begin
        freq_sel_last    <= freq_sel_sync;
        dds_config_data  <= select_frequency_word(freq_sel_sync);
        dds_config_valid <= 1'b1;
        dds_config_sent  <= 1'b1;
    end
end
```

`dds_config_valid`在首次锁定和每次开关变化时只保持一个10 MHz周期。非阻塞赋值使数据和valid在时钟沿后一起更新，并在下一个DDS采样沿被读取。

### 4.3 DDS实例

```verilog
wire               dds_valid;
wire signed [15:0] dds_data;

dds_sine u_dds_sine (
    .aclk                 (clk_10m),
    .s_axis_config_tvalid (dds_config_valid),
    .s_axis_config_tdata  (dds_config_data),
    .m_axis_data_tvalid   (dds_valid),
    .m_axis_data_tdata    (dds_data)
);
```

### 4.4 16位补码到14位偏移二进制

```verilog
always @(posedge clk_10m) begin
    if (!clk_10m_locked)
        dac_data_reg <= 14'h2000;  // 中点码8192
    else if (dds_valid)
        dac_data_reg <= {~dds_data[15], dds_data[14:2]};
end
```

最低2位被丢弃以匹配14位DAC；符号位翻转把有符号补码转换为偏移二进制，使零幅度对应中点码8192。

### 4.5 DAC转发时钟

```verilog
ODDR #(
    .DDR_CLK_EDGE("SAME_EDGE"),
    .INIT(1'b0),
    .SRTYPE("SYNC")
) u_dac_clk_oddr (
    .Q(dac_clk),
    .C(clk_10m),
    .CE(1'b1),
    .D1(1'b0),
    .D2(1'b1),
    .R(1'b0),
    .S(1'b0)
);
```

数据在10 MHz上升沿更新，`dac_clk`在约50 ns后的下降沿变为高电平，使外部DAC在数据稳定后采样。

## 8. 软件操作与硬件调试流程

1. 在Vivado中确认顶层为 `id_display`，约束文件端口名与最终顶层一致。
2. 配置Clock Wizard：100 MHz输入，10 MHz与50 MHz输出，启用 `locked`。
3. 配置DDS Compiler：10 MHz、32位相位、16位正弦补码输出、可编程相位增量。
4. 生成IP Output Products。
5. 将 `tb_task2_dds`设为Simulation Top，运行Behavioral Simulation。
6. 确认控制台显示 `PASS=12、FAIL=0`。
7. 依次运行Synthesis、Implementation和Generate Bitstream。
8. 打开Hardware Manager连接EGo1并下载 `.bit`。
9. 连接AD/DA板和示波器，按 `{SW2,SW1,SW0}`设置六个选择码。
10. 每切换一个频率，调整示波器时基、垂直档位和触发，保存频率、周期和峰峰值。

## 9. 实际遇到的问题和解决方案

### 9.1 DDS实例模板不一致

曾出现不带配置端口的固定DDS模板和带 `s_axis_config_tvalid/tdata`的可编程模板。最终任务要求运行时切换频率，因此检查最终XCI与wrapper后，选用可编程Phase Increment接口，并由专用Testbench核对配置字。

### 9.2 频率选择开关映射容易读反

通过老师提供的XDC和板上丝印确认：SW0-R1、SW1-N4、SW2-M4。报告统一用 `{SW2,SW1,SW0}`表示三位选择码。

### 9.3 原有仿真文件不能完整验证最终顶层

旧的 `tb_dds_sine.v`只适用于早期接口。重新建立 `tb_task2_dds.v`，直接实例化最终顶层并对六个控制字和六个输出频率进行自动检查。最终结果为12项通过、0项失败。

### 9.4 Program Device提示找不到`.ltx`

Vivado曾提示Probe file不存在。`.ltx`用于ILA探针映射，本轮外部DAC功能验证只需正确的bitstream。清除无效的Probe file路径后完成下载。该问题不影响已经生成的 `.bit`逻辑内容。

### 9.5 高频数字波形出现阶梯感

2 MHz输出在10 MSPS下每周期只有5个样本，数字仿真和未充分重建的DAC波形出现离散台阶符合采样原理。最终使用正确模拟输出连接和示波器设置，测得2.000 MHz、500.0 ns的周期关系。
